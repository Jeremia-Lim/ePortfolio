CS 499 Code Review

The code review represents the starting point for the enhancements completed throughout my CS 499 Computer Science Capstone. For this review, I examined the original version of my Android Inventory Management application that I developed during CS 360: Mobile Architecture and Programming.

The purpose of the review was to evaluate the existing application from the perspective of a more experienced developer and identify areas where the project could be improved. Instead of focusing only on whether the application functioned, I examined the organization, maintainability, efficiency, data management, and overall quality of the existing implementation.

Existing Functionality

The original Android Inventory Management application provides users with the ability to log into the application and manage inventory information. Its primary functionality includes adding inventory items, editing inventory quantities, deleting items, displaying inventory information, and managing notification permissions.

The original application demonstrated foundational Android development concepts including multiple activities, user input, interface design, local data storage, and interaction between the application's user interface and underlying data.

Code Analysis

During the code review, I evaluated the existing application to identify areas that could be improved as the project evolved. The review allowed me to examine the structure of the code, how responsibilities were distributed throughout the application, how inventory data was processed, and how persistent data was managed.

Revisiting an application that I had previously created also allowed me to recognize the difference between developing software that simply performs its intended functions and developing software that is organized, maintainable, efficient, and capable of being expanded.

Planned Enhancements

The enhancements identified during the code review were organized around the three major artifact categories required for the CS 499 ePortfolio: software design and engineering, algorithms and data structures, and databases.

For software design and engineering, my goal was to improve the application's overall organization, maintainability, and user experience. This involved evaluating how the application's components interact and identifying opportunities to create a cleaner and more structured implementation.

For algorithms and data structures, my goal was to improve how inventory information is processed and presented. These enhancements demonstrate the importance of selecting appropriate approaches for organizing, searching, sorting, and updating application data.

For databases, my goal was to strengthen the application's persistence layer and improve the separation between data access and other application responsibilities. This enhancement demonstrates my understanding of database operations and modern approaches to persistent data management in Android applications.

Connection to the Final ePortfolio

The code review establishes the baseline for the work presented throughout this ePortfolio. Each enhancement builds upon the original Android Inventory Management application while demonstrating a different area of computer science. Together, the review, enhanced artifact, and accompanying narratives demonstrate my ability to analyze existing software, identify opportunities for improvement, implement technical changes, and reflect on the results.
