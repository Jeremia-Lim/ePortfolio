Professional Self-Assessment

Completing the Bachelor of Science in Computer Science program at Southern New Hampshire University has transformed the way I approach technology, problem-solving, and my future as a software professional. When I began the program, I viewed programming primarily as the process of writing code that could accomplish a particular task. Throughout my coursework, however, I learned that professional software development requires much more than making a program work. It requires thoughtful design, effective communication, collaboration, efficient algorithms, reliable data management, security awareness, testing, and the ability to evaluate and improve an existing solution. Developing my ePortfolio gave me the opportunity to bring these skills together and demonstrate how I have grown from completing individual programming assignments into approaching problems with the mindset of a software engineer.

Collaboration and Communication

One of the most important areas of growth throughout the program has been my ability to collaborate and communicate within technical environments. Computer science solutions rarely exist in isolation. Developers must understand requirements, explain technical decisions, receive feedback, and communicate with people who may have different levels of technical knowledge. Through discussion assignments, project planning, code reviews, documentation, and presentations, I learned how important it is to adapt technical communication to the intended audience.

My CS 499 code review was particularly valuable because I had to examine an existing application, identify weaknesses, explain why those weaknesses mattered, and propose enhancements before implementing them. Rather than simply changing the code, I had to communicate the reasoning behind my decisions as if I were explaining the project to peers or a manager.

Data Structures and Algorithms

Data structures and algorithms were another major area of development during the program. Earlier in my education, I often focused on whether a program produced the correct result. My later coursework taught me to also consider how efficiently the program reaches that result. I gained experience working with structures such as arrays, lists, trees, and other collections while considering searching, sorting, iteration, and computational efficiency.

My work with a binary search tree demonstrated how selecting an appropriate data structure can make information retrieval more organized and efficient. These experiences taught me to evaluate computing solutions based not only on functionality but also on performance, scalability, and the trade-offs associated with different approaches.

Software Engineering

Software engineering has become one of the strongest areas represented by my coursework and ePortfolio. Through projects involving Android development, full-stack applications, object-oriented programming, and software architecture, I learned to divide larger problems into manageable components.

My Android Inventory Management application is a strong example of this progression. The original application was created during CS 360: Mobile Architecture and Programming and provided core inventory-management functionality, including user login, adding inventory items, editing quantities, deleting items, and managing notification permissions.

Returning to the project during CS 499 allowed me to evaluate it from a much more experienced perspective. I identified opportunities to improve its architecture, organization, maintainability, data handling, and overall design. Enhancing an existing application also taught me the importance of modularity and designing software that can continue evolving over time.

Database Development

Database development has also played an important role in my growth as a computer science student. Throughout the program, I worked with relational and nonrelational approaches to data management and learned that storing information effectively requires much more than simply saving values.

My coursework gave me experience with SQL, SQLite, MongoDB, CRUD operations, persistent storage, database organization, and the interaction between application logic and stored data. During my CS 499 database enhancement, I continued developing this knowledge by improving the persistence layer of my Android Inventory application using a more structured database architecture.

Security

Security became equally important as my technical abilities developed. CS 405: Secure Coding was especially influential in shaping how I evaluate software. Working with vulnerabilities such as SQL injection and buffer-related problems demonstrated how seemingly small development decisions can create serious security consequences.

I learned that security should influence requirements, architecture, input handling, data management, testing, and maintenance from the beginning of the development process. Practices such as validating input, limiting unnecessary permissions, protecting stored information, identifying vulnerable dependencies, and testing unexpected conditions became part of the way I evaluate software.

Professional Growth

Other projects throughout the Computer Science program expanded my abilities beyond traditional application development. My work with machine learning and reinforcement learning introduced me to experimentation, parameter selection, performance evaluation, and iterative improvement. Coursework involving computer graphics, networking, reverse engineering, mobile development, databases, and secure coding further broadened my understanding of the field.

Developing my CS 499 ePortfolio brought these different areas of knowledge together. I selected my Android Inventory Management application as the primary artifact because it provides a clear demonstration of my growth as a developer. Instead of presenting several unrelated projects, enhancing the same application across software design and engineering, algorithms and data structures, and databases allowed me to demonstrate how different areas of computer science contribute to one complete software system.

The software design and engineering enhancement demonstrates my ability to evaluate an existing codebase and improve its architecture and functionality. The algorithms and data structures enhancement demonstrates my ability to think about how information is organized, processed, searched, sorted, and presented efficiently. The database enhancement demonstrates my ability to improve persistent data management and separate database responsibilities from other application logic.

My professional goal after graduation is to begin a career in software engineering where I can continue strengthening my technical abilities while contributing to meaningful software projects. Although completing my degree represents an important milestone, I recognize that computer science requires continuous learning. Programming languages, frameworks, development tools, security threats, and industry practices will continue changing.

This ePortfolio represents the progression of the skills I developed throughout my degree and provides tangible evidence of my ability to design, evaluate, enhance, and communicate computing solutions. Together, these components demonstrate my preparation to transition from a computer science student into a professional software environment. I am completing the program with stronger technical skills, a more developed security mindset, greater confidence in my problem-solving abilities, and an understanding that becoming an effective software engineer requires continuous improvement.
